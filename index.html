12 月 18 日
PART 01

模型与工具怎么选

  • 工具无关：这套系统在任何 Agent 工具里都能用
  • 把本地资料 / 系统和模型解耦，不被任何一家大模型公司绑架
  • 项目文件夹放本地，上面接哪个模型、哪个 Agent 都能换
AGENT 入门

Agent = 大模型 + 框架

  • 发动机 + 车架 = 一辆能开的车
  • 第一个体验：让 AI 直接操作你的电脑（整理桌面、改文件、改设置、装软件）
  • Grok Bot 基础设置：一个 bot，一件事；珍惜上下文
PART 02 · 03

先看结果，再看全景

  • 拆解最近的真实项目
  • 完整项目三阶段：前期 · 中期 · 后期
  • 前期：采访大纲 Skill、每日信息收集 Skill、文案 Skill
中期 · 剪辑项目

六个 Skill，各管一段

  • 文稿 → 人工审稿闸 → 粗剪 → 包装 / 封面并行 → 交付
  • AI 先出稿，人只做一件事：判断 OK 不 OK
  • 协作：做一个网页用于协作与交付
后期 · 素材二次利用

拍一次，不止是视频

  • 公众号：用拍摄素材写文章并完成排版
  • 做教程：把素材里的内容整理成教程
  • 方法论 → Skill → 工具
现场动手 实操

完整剪一条素材

  • 一条素材做精剪包装
  • 出 3 张封面
  • 根据视频内容出标题文案
  • 完整走一遍剪一条素材的流程
DAY 2 · SKILLS

Skill：从 AI 产品用户，到 AI 系统构建者

把流程固定成 Skill，动手做出来。Skill 是 AI 发展过渡阶段最好的载体——轻量、通用、迭代快。

12 月 19 日
PART 01

Skill 是什么

  • 三层理解：文件 / 提示词 → AI 时代的 APP → 能力工具化的最小载体
  • 本质：可复用、可被召唤的能力包（按结构组成的文件夹）
  • 技术底座：渐进式加载，description 决定何时触发
PART 02

创建 Skill 的 5 种方式

  • 手写 · 用 skill-creator · 用已有 SOP / 资料生成
  • 先做任务，再总结（六步把一次成功变成 Skill）
  • 找现成的改：/find skill 或 GitHub
现场动手 实操

今天要做的 Skill：从简单到复杂

信息收集 Skill / bot文案 Skill封面 Skill粗剪 Skill精剪 Skill把自己的常见工作做成 Skill10 分钟录音 → 工具
PART 03

Skill 做好不是终点

  • 小迭代：发现问题当场修，写回 Skill 文件
  • 大迭代：重跑，不打补丁
  • Skill 库：让 AI 把所有 Skill 做成飞书多维表格
PART 04 · 05

万物皆可 CLI · 从任务到项目

  • CLI 天生适合 Agent 用；飞书 CLI 让 AI 操作飞书
  • 项目 = 规则（AGENTS.md）· 资料 · 能力
  • Skill 靠一个写死的交接文件串起来
DAY 3 · 串成项目

把 Skill 串成
一个完整项目

今天把流程变成 Skill；明天，把 Skill 串成项目。把多个 Skill 串起来，变成一个能持续积累、迭代、自动化的完整项目。

12 月 20 日
串联原则

不靠“AI 记得住”

  • 上一个 Skill 的输出，就是下一个 Skill 的输入
  • 交接格式定死，任何一环单独升级都不影响别人
  • 例：粗剪 Skill 产出 packaging-handoff.json，包装 Skill 只认交接包
项目结构

一个文件夹里有三样东西

  • 规则：项目级 AGENTS.md，这个项目的特殊要求
  • 资料：相关的资料、素材、产出
  • 能力：为这件事沉淀的 Skill 和工具
现场动手 实操

建立你的项目：建文件夹 → 想流程 → 建 Skill → 串联起来

  • 从临时工到私人助理：给 AI 建了工位、做了专门的培训，它开始变成长期的合作伙伴
  • 学完之后，你会有一套属于自己的 AI IP 孵化 / 个人 IP 工作流
